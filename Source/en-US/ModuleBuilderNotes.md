# en-US/

The locale-specific help folder for English (US). PowerShell's `Get-Help`
system looks for external help files here at runtime.

Add this folder to `CopyPaths` in `Build.psd1` when MAML help is adopted.
Comment-based help inside each function is the simpler alternative.

## Standard files

| File | Purpose |
|------|---------|
| `<ModuleName>-Help.xml` | MAML help file. Generated by Microsoft.PowerShell.PlatyPS (`Export-MamlCommandHelp`) from Markdown command docs. |
| `about_<ModuleName>.help.txt` | `about_` topic shown by `Get-Help about_<ModuleName>`. Plain text, hard-wrapped at 80 chars. |

## Workflow (if adopted)

1. Author function docs as comment-based help in each `.ps1` file. See
   [MIGRATING.PLATYPS.md](../../MIGRATING.PLATYPS.md) for the format.
2. Generate the Markdown command pages with `Docs.ps1`.
3. Import them and export MAML to produce `<ModuleName>-Help.xml`:
   ```powershell
   Import-MarkdownCommandHelp -Path ./Docs/<ModuleName>/*.md |
       Export-MamlCommandHelp -OutputFolder ./Source/en-US
   ```
4. Add `'./en-US'` to `CopyPaths` in `Build.psd1` so ModuleBuilder copies it
   to the output folder.
